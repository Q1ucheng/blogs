    Welcome to CS 106B！¶

    起因：预感研究生阶段更多地会和要求实时性的硬件打交道，C++ 的学习就必不可少了。这门课程感觉和 UCB CS61A 差不多，用 C++ 讲解数据结构与算法，于是准备把这门课过一遍学习 C++ 的同时也能复习一下基本的算法，找回一些手动coding的感觉。

    课程概览¶

    CS106B 是斯坦福计算机系的核心课程之一，主要讲授数据抽象与算法分析。与 CS106A（Python/Java 入门）不同，这门课更关注"底层"与"原理"：

    核心内容¶

    • 递归与回溯 (Recursion & Backtracking)
    • 内存管理 — 指针与动态分配
    • 数据结构实现 — 链表、树、图、哈希表
    • 经典算法 — 排序、查找、图算法
    • 算法效率分析 — Big-O 复杂度

    课程形式¶

    • 7 次编程作业（占总成绩 45%，支持 Pair Programming）
    • 期中 + 期末考试（闭卷，但允许带一张双面手写笔记纸）

    开发环境¶

    课程使用 Qt Creator 作为 IDE，并配套斯坦福自研的 C++ 库（simpio.h、Stanford C++ Library 等），这让初学者能更专注于逻辑而非繁琐的输入输出处理。

    我自己在学习时使用Clion 2023。

    什么是 C++？¶

    C++ 由 Bjarne Stroustrup 于 1983 年在 C 语言基础上开发，增加了面向对象等特性。它至今仍是系统编程、游戏引擎、高频交易等领域的首选语言之一。

    C++ 与 Java 的关键区别¶

    特性 C++ Java
    执行方式 编译为平台相关的机器码 编译为字节码，JVM 解释执行
    文件扩展名 .cpp / .h .java
    入口函数 int main()，不需要放在类中 public static void main(String[])，必须在类内
    内存管理 手动（指针/new/delete） 自动垃圾回收
    平台依赖性 可执行文件依赖平台 "一次编写，到处运行"

    C++ 的编译过程¶

    C++ 采用分离编译 + 链接模型： 1. 每个 .cpp 源文件被编译成 .o（目标文件） 2. 链接器（Linker）将多个目标文件与库文件合并，生成最终的可执行文件

    这意味着 C++ 程序不像 Java 那样直接分发 .class 字节码，而是生成依赖操作系统的二进制文件。

    逐行解析¶

    代码 含义
    /* ... */ 多行注释，编译器会忽略
    #include <iostream> 预处理指令，引入输入输出流库，让我们能使用 cout
    using namespace std; 引入 std 命名空间。否则每次都要写 std::cout
    int main() 程序入口函数。C++ 的 main 函数不属于任何类，且必须返回 int（0 表示成功）
    cout << ... 输出流对象，<< 是"插入"运算符
    endl 换行符，同时刷新缓冲区。等价于 \n，但跨平台更兼容
    return 0; 向操作系统返回状态码 0，表示正常结束

    控制台输入输出与 Stanford 库¶

    1. 输出：cout¶

    C++
    1
    cout << "You are " << age << " years old!" << endl;
    - cout 可以连续使用 << 拼接多个表达式 - endl 不仅换行，还会刷新输出缓冲区，确保内容立即显示

    2. 输入：为什么课程不鼓励直接用 cin？¶

    标准 C++ 的 cin 有几个对新手不友好的问题： - 输入类型错误时不会友好提示，容易导致程序崩溃 - 读取整行文本时行为诡异（与 >> 运算符的缓冲区交互复杂） - 与课程提供的 Stanford 库兼容性不佳

    3. Stanford simpio.h 库¶

    课程提供了 simpio.h（Simple I/O），封装了更友好的输入函数：

    函数 功能
    getInteger("prompt") 反复提示，直到用户输入合法整数，返回该整数
    getReal("prompt") 同上，读取 double 类型
    getLine("prompt") 读取一整行文本（包含空格），返回 string
    getYesOrNo("prompt") 反复提示 Yes/No，返回 bool

    示例:

    课堂练习：Stanford vs Cal（Big Game）¶

    题目要求¶

    • 分别读取两队的得分
    • 判断胜负并输出结果

    /*
 * This program prints a score of a football game.
 */
#include <iostream>
#include "simpio.h"
using namespace std;

int main() {
    int stanford = getInteger("Stanford points scored?");
    int cal = getInteger("Cal points scored?");

    if (stanford > cal) {
        cout << "Stanford won!" << endl;
    } else if (cal > stanford) {
        cout << "Cal won!" << endl;
    } else {
        cout << "A tie." << endl;
    }

    return 0;
}
